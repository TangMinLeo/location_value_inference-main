- routine(守规律)偏好高 → 按标准入场路线直接到座位
- entertainment(娱乐)偏好高 → 尽快入座等待演出开始

【观演阶段】

- curiosity(好奇)偏好高 且 value较低 → 去走廊走走探索，之后返回座位

- 需要如厕 → 前往厕所，之后返回座位
- 默认 → 保持在座位

【散场阶段】
- quiet(安静)偏好高 → 直接前往场馆外出口
- curiosity(好奇)偏好高 → 先去舞台中心/事故发生地(若有)看看，再去场馆外
- social(社交)偏好高 → 在走廊/出口等待同伴，再去场馆外
- routine(守规律)偏好高 → 按指定路线有序离场

- 默认 → 前往场馆外出口

决策步骤：
1) 确认当前子场景（入场/观演/散场），选择对应的决策规则；

4) 若匹配的行为模式需要中转（如"先去商店再去座位"），则目的地序列包含多个地点，按顺序排列；
5) 若当前已有任务（如如厕、回应他人），优先处理任务相关目的地；
6) 检查目的地是否可达（在可选目的地列表中），若不可达则选择最接近的可达目的地。

反模式警告（必须避免）：

- 不要让好奇心低的智能体在散场时绕去舞台中心；
- 不要忽略 pref>0.6 且 value<40 的维度，这些维度需求紧迫，应优先响应；
- 不要给所有智能体相同的目的地，价值差异必须体现为行为差异；
- 入场阶段最终目的地必须是座位（无论是否绕行）；
- 散场阶段最终目的地必须是场馆外出口（无论是否绕行）。
